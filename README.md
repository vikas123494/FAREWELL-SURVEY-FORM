# Farewell Party Survey Form

A simple and responsive HTML-based survey form created to collect feedback and preferences for a farewell party.

## 📌 About the Project

This project is a beginner-level web development project built using HTML.

The form allows users to:

- Enter their name, email, and age
- Select their role (Student, Faculty, or Alumni)
- Indicate whether they will attend the farewell party
- Select the aspects they liked about the event
- Submit comments or suggestions
- Reset the form
- Visit the REVA University website

## 🛠️ Technologies Used

- HTML5
- Basic HTML Forms
- Form Inputs
- Select Dropdowns
- Radio Buttons
- Checkboxes
- Textarea
- Buttons
- Hyperlinks
